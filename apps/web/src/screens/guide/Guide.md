# Guide

Figma 143:523, a guide, as its Get a SIM Card or eSIM instance draws it.
Every section is optional and the page holds together without any of them.
Database text is marked with the language it is actually in, so a guide not
yet translated reads correctly inside the reader's language and says so.

Where the guide links researched rules, The rules that apply follows the quick
answer (SB-257), each rule drawn by RuleAnswer. The prerendered file carries the
rule for everyone. The reader's own answer, for the nationality, place and
status the address names, is asked for in the browser only and without
suspending, so it replaces the rule for everyone when it arrives, and again
whenever the address changes. The button beside a missing detail opens the
details panel in the header. The design draws no rule answer, so this is a
departure, recorded in DESIGN.md.
