# AddressShell

The shell for the address the reader is at: the country it names once the
database has confirmed it, and whether the page opens owning Ask. Both come
from the address, not from the page after it mounts (SB-161), so the first
render has them, the prerender's included, and nothing renders twice.

It carries what the reader has said of themselves too, once the country has
confirmed each against its own lists: where they come from, where they live,
their residence status, their role, and where they work (SB-318). The route
below it confirms the same things through the same helper, so the panel can
never show a detail the route rejected, or forget one it accepted. A detail
added to that list belongs here.
