# SourceCard

Figma 30:84: who published it, when we last checked, whether it is verified, in that order.

## Props

- `publisher`: Who stands behind it, "Republic of Türkiye".
- `institution`: The institution, "Ministry of Trade · Trade Registry".
- `checkedAt`: When it was last checked, or last reachable when it is unavailable. As the API sends it, "2026-08-24".
- `official`: False for an operator's or a company's own page, which the card says.
- `note`: What this source is the source for, in place of the standing closing line.
