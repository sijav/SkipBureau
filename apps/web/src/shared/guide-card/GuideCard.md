# GuideCard

Figma 18:14, 360x154. The verified date is part of the card, not a detail on
the page behind it: it is the one sign a reader has that this is current.

## Props

- `category`: The area it belongs to, "Residence and immigration".
- `description`: One sentence of what the reader actually gets.
- `verifiedAt`: When it was last verified, as the API sends one: "2026-08-24".
