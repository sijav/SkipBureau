# برچسب وضعیت

برچسبی کوچک که می‌گوید کاری در چه وضعی است، از گره `13:26` در فیگما. آن را بر
اساس معنای وضعیت انتخاب کنید؛ رنگ‌ها از آن پیروی می‌کنند و ویژگی رنگ وجود ندارد.

```tsx
<StatusTag status="deadline">۱۲ روز تا موعد</StatusTag>
```

| وضعیت | معنا |
|---|---|
| `official` | از خود نهاد آمده است |
| `verified` | با منبعی رسمی سنجیده شده، همراه با زمانش |
| `needsContext` | پاسخ به وضعیت خواننده بستگی دارد |
| `deadline` | پای تاریخی در میان است |
| `warning` | پیش از اقدام بررسی کنید، مثلاً پیش از پرداخت |
| `blocked` | خواننده متوقف شده و باید کاری کند |
| `waiting` | خواننده باید منتظر دیگری بماند، کاری از او ساخته نیست |
| `completed` | انجام شده |

سه وضعیت عمداً کهربایی مشترکی دارند، به قاعدهٔ خود طراحی: موعد و وابسته‌به‌وضعیت
هر دو به زمان یا شرایط حساس‌اند، و متن برچسب آن‌ها را از هم جدا می‌کند، نه رنگی
سوم. انتظار خنثی است چون صبر می‌خواهد، نه اقدام.

معنا را کلمات می‌رسانند، پس رنگ هرگز تنها نشانه نیست. مربع کوچک پیشِ برچسب
تزئینی است و با `showMark={false}` خاموش می‌شود.
