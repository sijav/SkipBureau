# Germany's states

**Agreed 2026-09-15**, after two turns in `talk/germany/states.md`. The sign-off turn
found no overclaim and asked that one sentence cite ISO's page beside Destatis's. Every name
and code below is quoted from its page, not recalled.

## What a reader is told

**ISO 3166-2 lists 16 Länder for Germany**, each with a code of DE- followed by two letters,
from DE-BW to DE-TH[^iso-3166-2-de-states].

**The Federal Statistical Office lists the same 16 Länder by the same names**, each with a
two-digit number and its abbreviation in brackets, which is the two letters of its ISO
code[^destatis-bundeslaender][^iso-3166-2-de-states]. The Basic Law's preamble names the 16 Länder in the same
forms[^gg-preamble-laender].

**No regional variation.** These are places, and the three lists agree.
