# Turkey's provinces

**Agreed 2026-09-15**, after two turns in `talk/turkey/provinces.md`. The sign-off turn
found nothing to correct. Every name and code below is quoted from its page, not recalled.

## What a reader is told

**ISO 3166-2 lists 81 provinces for Turkey**, each with a code of TR- followed by two
digits, from TR-01 to TR-81, each code once[^iso-3166-2-tr-provinces].

**NVI's directory of provincial population directorates names 81 provinces**, each
once[^nvi-province-directorates].

**The two lists print the same 81 names, except for one.** ISO writes
Hakkâri[^iso-3166-2-tr-provinces] and NVI writes Hakkari[^nvi-province-directorates]. TDK's
spelling rules write Hakkâri[^tdk-hakkari-circumflex]. We could not find an instrument that
settles the spelling. We use NVI's names.

**No regional variation.** The one difference above is between two sources' spellings, not
between provinces.
